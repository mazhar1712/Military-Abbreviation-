# Military Abbreviation Converter

A military-themed web interface for the existing Military Abbreviation Converter project.

## Features
- Abbreviation ↔ full-form conversion
- Military abbreviation search
- TXT / PDF / scanned PDF / DOCX loading
- Result highlighting and copy
- TXT / Word / PDF export
- Light/dark mode support from the original project
- Responsive mobile-first interface
- Bangladesh Army-inspired olive/khaki camouflage visual design

## Run
Open `index.html` in a modern browser, or serve the folder with any static web server.

## GitHub Pages
Upload the repository to GitHub and enable **Settings → Pages → Deploy from a branch** using the `main` branch and `/ (root)`.

## Credits
The converter logic and abbreviation database are based on the supplied `Mil_Abbr_Converter` project. The visual layer has been redesigned for this version.
